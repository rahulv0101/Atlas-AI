# Frozen chart-research experiments

Fixed a reproducibility defect in the chart-driven research worker: saved candidate genes were retained, but later forward evaluation used the current simulator settings and current source implementation. A restart or settings change could therefore append outcomes generated by different methods to the same experiment.

Each new batch now saves a versioned protocol before evaluating its candidates. The protocol includes symbol/timeframe, point size, hold duration, slippage assumption, break-even/trailing/stale-exit settings, relevant source hashes and Python/numpy/pandas/MT5 versions. Each candidate also stores a hash of its full saved gene list. The forward evaluator restores the saved simulator settings, explicitly keeping execution disabled.

Changed rules, source, dependencies, incomplete protocol or market scope block further forward appends. A worker detects source changes during its lifetime and requires a restart; a change during evaluation prevents result publication. Existing observations are retained. Legacy experiments are marked `legacy_protocol_unverified`; their missing provenance is never filled in retrospectively. The worker starts a separate new batch under the current protocol when a new closed bar is available, using its existing bounded invention rules. No live strategy, entry threshold, risk limit or execution authority changes.

The scheduler report records the latest integrity state, blocked-batch count and separate verified-protocol/unverified-protocol forward outcome counts. "Verified protocol" means method consistency, not profitable performance or broker qualification. The existing four-batch active limit and historical archive remain in force. A local copy of the pre-deployment research state preserves all 154 forward paper outcomes present at the snapshot.

Validation: 71 related research/evolution checks passed. The final eight protocol cases also passed, including actual forward replay retaining the original slippage charge after a runtime setting changes, rejection of changed genes/dependencies, preservation of legacy observations, and failure to publish a result when source changes mid-evaluation. The prior complete system run passed 1,870 tests; it predates this repair and is not presented as a fresh full run of these changes.

Deployment uses the normal guarded-demo launcher after confirming the configured demo is flat. The natural-lifecycle observer and the separate frozen cost experiment are retained. These changes fix research integrity; they do not create a profitable strategy or manufacture a natural broker lifecycle. Both still require qualifying subsequent evidence. Raw deployment, test and state artifacts remain local in `docs/diagnostics` and `storage`.
